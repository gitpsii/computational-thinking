
# Computational Thinking — MIT 18.S191

My solutions, implementations, and experiments while working through **MIT 18.S191: Introduction to Computational Thinking**.

The course focuses on using programming and computational methods to understand mathematical and scientific problems. Most of the work here is written in **Julia**, with an emphasis on learning how to translate mathematical ideas into efficient, readable code.

## What I’m Learning

The repository covers topics including:

* Julia fundamentals and multiple dispatch
* Arrays, indexing, broadcasting, and comprehensions
* Functions and higher-order functions
* Numerical methods
* Image processing
* Convolution and filtering
* Gaussian and box blurring
* Edge detection
* Data manipulation and visualization
* Mathematical modeling
* Computational approaches to scientific problems

A major part of the course is not just writing code, but understanding **how a computational representation of a problem connects to the underlying mathematics**.

## Some Topics I've Worked With

### Image Processing

One of the more interesting parts of the course has been implementing image-processing operations from the ground up.

This includes working with:

* RGB and grayscale images
* Pixel-wise operations
* Image quantization
* Noise generation
* Convolution
* Kernel construction
* Gaussian blur
* Box blur
* Sobel edge detection
* Boundary handling and image extension

For example, convolution can be used to apply a small numerical kernel across an image to perform operations such as smoothing or edge detection.

### Numerical & Mathematical Computing

The course also connects programming directly with mathematical concepts. Implementations involve working with:

* Arrays and matrices
* Numerical approximations
* Functions and transformations
* Mathematical models
* Iterative algorithms
* Discrete representations of continuous problems

The goal is to understand the computation rather than treating numerical routines as black boxes.
